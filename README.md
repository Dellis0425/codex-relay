# Codex Relay

Codex Relay is an AutoHotkey v2 utility for scheduling delayed prompts to the ChatGPT desktop app for Codex workflows.

## Current features

- Schedule a Codex prompt for a specific time
- Add a safety buffer after a usage reset
- Automatically focus the ChatGPT desktop app
- Type a continuation prompt
- Optionally press Enter and send it
- Default schedule is approximately five hours from the current time

## Hotkey

`Ctrl + Alt + K` opens the scheduler.

## Requirements

- Windows
- AutoHotkey v2
- ChatGPT desktop app
